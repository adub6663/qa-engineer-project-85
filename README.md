# Codebattle - игра для программистов
## О проекте 
**Codebattle** - это проект с открытым исходным кодом, в котором два программиста соревнуются в скорости решения одной задачи на разных языках программирования. Побеждает тот, кто быстрее решит задачу.
## Основные возможности
- Решение задачи на скорость против другого игрока.
- В игру можно играть с любым человеком, с ботом или другом (игра будет доступна по ссылке)
- Выбор игры по уровню сложности
- Задачи даны на двух языках — русском и английском
- Другие пользователи могут следить за ходом игры
- Есть чат, в котором общаются зарегистрированные пользователи
- Завершенная игра доступна в записи
- Рейтинг игроков за неделю, месяц и все время
